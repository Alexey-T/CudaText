     other OS-es use the LCL drop-files support). Dropped files/folders are

     first 5-px move), so an inner drop was impossible. Now an inner
     drag&drop runs while the cursor stays over the tree, and only when the
     cursor leaves the tree the gesture becomes a drag-out to other apps
     (Explorer etc), as before. Inner drops:
     - root node onto another root node / onto the project header: reorder
       the root nodes (visible with "Sorting order" cleared in config)
     - file/folder onto a folder node: move it on disk into that folder
       (same as the plugin's Cut+Paste), with safety checks (no overwriting,
       no move into itself / its own subfolder); if the moved path was the
       project's main file, the project is updated
     - file/folder onto the project header: add it as another root node

     folder for ~0.7 s unfolds it, and the click which LCL fires on the
     drag's mouse-up is suppressed (it must not open the dropped-on node).

     items by mouse coordinates)
